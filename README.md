# Starter projektu — Claude Code Starter

To jest szkielet folderu, w którym powstanie Twoja strona. Same puste pliki z nagłówkami. Treść dopisujesz w kolejnych lekcjach.

## Co zrobić po rozpakowaniu

1. **Zmień nazwę folderu** na nazwę swojego projektu - małe litery, bez polskich znaków, bez spacji, myślniki zamiast spacji. Np. `moje-portfolio`.
2. **Przenieś go w dobre miejsce** — jeden katalog na wszystkie projekty, np. `~/projekty/`, a w środku ten folder osobno. Najelpiej tak organizować projekty
3. **Otwórz go w edytorze kodu** — cały folder, nie pojedynczy plik.
4. **Uruchom w nim Claude Code** i lecimy dalej.

## Co jest w środku

```
context/
  brief.md         ← wypełniasz w lekcji 5
  brand.md         ← wypełniasz w lekcji 6
assets/            ← grafiki, ikony, zdjęcia
.gitignore         ← rzeczy, których nie wysyłamy na GitHuba
```

Reszta plików, które pojawią się po drodze to: `CLAUDE.md` w lekcji 7, `sitemap.html` w 8, `wireframe.html` w 9, `teksty.md` w 11, `DESIGN.md` w 13, `styleguide.html` w 14.

Kod samej strony powstaje dopiero w module **Tworzenie stron www** — w tym module przygotowujemy wszystko, co jest potrzebne, żeby go dobrze napisać.

## Zasada, o której warto pamiętać

Wszystko, co ważne dla projektu, mieszka **w tym folderze**. Nie w Google Docsie, nie w Notion, nie na kartce ani w Twojej głowie. Claude czyta to, co ma w folderze — brief w chmurze dla niego nie istnieje.
